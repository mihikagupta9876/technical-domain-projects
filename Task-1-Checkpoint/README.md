# Checkpoint

## QR + Geo-Verified Attendance System

Checkpoint is an attendance system that uses QR codes and geolocation verification.

## Features

- Organizer event creation
- QR code generation
- QR code scanning
- Geolocation verification
- Attendance tracking
- Attendance statistics
- CSV report export

## Technologies Used

- HTML
- CSS
- JavaScript
- QRCode.js
- jsQR
- Browser Geolocation API
- LocalStorage

## How to Run

1. Open `index.html` in a browser.
2. Select the Organizer option.
3. Create an event.
4. Generate the QR code.
5. Select the Attendee option.
6. Scan the QR code.
7. Allow location access.
8. Complete attendance check-in.
